# 🎃 Максимально своя игра
Локальная игра для ведущего и друзей. Node.js 20 или новее, без внешних зависимостей и без интернета во время игры.

## Запуск
Откройте терминал в папке проекта и выполните `npm start`. Откройте в браузере адрес `http://localhost:3000`. Для доступа с другого устройства в той же сети используйте локальный IP компьютера и порт 3000. Остановить сервер: Ctrl+C. Подходит для macOS, Windows и Linux.

Добавьте участников кнопкой «Участник». Выберите раунд и вопрос. Таймер начинается автоматически; значение по умолчанию 30 секунд, настройка 5–300 секунд применяется к следующим вопросам. Физические кнопки не подключены к приложению: ведущий нажимает паузу вручную. Кнопки ✓ и ✕ изменяют счёт и ставят таймер на паузу; после ошибки можно продолжить таймер для других игроков. Правильный ответ завершается ведущим кнопкой «Завершить вопрос». «Вернуть на табло» оставляет вопрос доступным. Ответ раскрывается отдельно. Повторные стоимости обозначают разные вопросы.

Состояние автоматически сохраняется сервером в `.local/state.json`, включая открытый вопрос и таймер. Не запускайте несколько ведущих одновременно. «Отменить» отменяет действия текущего открытия страницы; история отмены не сохраняется после обновления. Для резервной копии остановите сервер и скопируйте `.local`. Материалы находятся в `public/questions.json` и `public/media`.

Включено 47 вопросов, 9 категорий, два раунда. Фотографии ответов появляются только после раскрытия. Без скримеров, внешних шрифтов и звуков. Личные фотографии хранятся в репозитории: учитывайте это при выборе его видимости.
