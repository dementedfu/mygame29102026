# 🎃 Максимально своя игра

Игра для дня рождения: 47 вопросов, 26 фотографий, 9 категорий и два раунда. Весёлый Хэллоуин без скримеров. Ведущий управляет всем с общего экрана, физические кнопки работают отдельно.

## Как запустить на Windows

1. Установите **Node.js LTS** с https://nodejs.org/ (нужна версия 20 или новее).
2. Скачайте проект: **Code → Download ZIP**, затем распакуйте архив.
3. Дважды нажмите **«Запустить игру.bat»** в распакованной папке.
4. Когда сервер запустится, откройте в браузере **http://localhost:3000**.

Оставьте чёрное окно открытым, пока играете. Для остановки нажмите в нём **Ctrl+C**. Установка npm-пакетов не требуется.

Если Windows не открывает BAT, откройте папку с `package.json` в Проводнике, в адресной строке введите `cmd`, нажмите Enter и выполните `npm start`. Права администратора не нужны.

## macOS и Linux

Установите Node.js LTS. Откройте терминал в папке проекта и выполните `npm start`. На Mac также есть файл **«Запустить игру.command»**; если macOS не разрешает его запуск, используйте терминал. Откройте **http://localhost:3000**. Остановка — **Ctrl+C**.

Во время игры интернет не нужен. Для доступа с другого устройства в той же Wi-Fi-сети используйте локальный IP компьютера и порт 3000. Управляйте игрой из одной вкладки: совместная работа нескольких ведущих не предусмотрена.

## Как провести игру

- Нажмите **«＋ Участник»**, введите имя и выберите один из **7 аватаров**: 🎃 👻 🦇 🐈‍⬛ 🧙 🧛 🧟. Нажатие на карточку игрока меняет имя, аватар и счёт.
- Выберите вопрос. Таймер запускается автоматически. По умолчанию — **30 секунд**; в настройках можно выбрать от 5 до 300 секунд для следующих вопросов.
- Услышав физическую кнопку, нажмите **Пробел** или **«Пауза»**. Пробел повторно продолжает отсчёт. **Esc** ставит вопрос на паузу, не закрывая его.
- **✓** прибавляет стоимость вопроса, **✕** вычитает. Отрицательный счёт разрешён. После ошибки нажмите **«Продолжить»**, чтобы дать ответить остальным.
- За один вопрос результат каждого игрока принимается один раз. После верного ответа остальные кнопки начисления блокируются. Если ошиблись — нажмите **«↶ Отменить»** прямо в окне вопроса или **Ctrl+Z** (на Mac **Cmd+Z**).
- Кнопка **«Показать ответ»** или клавиша **A** раскрывает текст и фотографии ответа. Горячие клавиши работают и при русской раскладке. Ведущий может назначить очки и после раскрытия ответа.
- Нажмите на фотографию для увеличения. Если таймер шёл, он встанет на паузу. После закрытия фото возобновите его вручную.
- **«Завершить вопрос»** отмечает его сыгранным. **«Вернуть на табло»** сохраняет его доступным; если очки уже изменились, сначала отмените начисление/списание.
- Когда время вышло, ведущий всё равно может принять ответ или заново запустить отсчёт кнопкой **«↻ Таймер»**. Мягкий сигнал окончания можно включить в настройках; по умолчанию звуки отключены.
- После первого раунда появится переход ко второму. **«🏆 Итоги»** показывает места по счёту. При ничьей игроки делят место, дополнительных вопросов нет.
- **F** разворачивает игру на весь экран. В полях ввода горячие клавиши не срабатывают.

## Сохранения

Игра автоматически сохраняется в `.local/state.json`; перед обновлением сохранения сервер держит предыдущую копию в `.local/state.json.bak`. При повреждении основного файла он пробует прочитать резервный. Внизу страницы виден статус сохранения. Сохранения первой версии поддерживаются, аватары добавляются автоматически.

Открытый вопрос и таймер восстанавливаются после обновления страницы. Идущий таймер учитывает время, прошедшее с последнего запуска, даже если вкладку закрыли. История **«Отменить»** хранится только до обновления страницы; при отмене таймер всегда на паузе с фактическим остатком времени.

В **«Настройки → Скачать копию»** можно сохранить JSON-файл со счётом и сыгранными вопросами, а затем восстановить его через **«Загрузить копию»**, в том числе на другом компьютере. При загрузке копии таймер всегда на паузе. JSON не содержит фотографий — на втором компьютере нужна папка проекта со всеми материалами. При потере связи с сервером игра оставляет аварийную копию в браузере и повторяет сохранение; не закрывайте вкладку, пока сервер не заработает, или скачайте JSON.

Чтобы перенести сохранение при обновлении проекта, сначала остановите сервер и скопируйте папку `.local` в новую папку проекта. Другой вариант — экспортировать JSON через настройки и импортировать после обновления. **«Начать новую игру»** сбрасывает счёт и табло, сохраняя игроков и аватары; действие требует подтверждения.

## Возврат к первой версии

Оригинальная первая версия сохранена в GitHub тегом **v1.0.0**, коммит `48ea6c3`.

Без Git: откройте https://github.com/dementedfu/mygame29102026/tree/v1.0.0 → **Code → Download ZIP**. Распакуйте в отдельную папку и запустите `npm start` в ней. Так новая версия останется рядом, и можно выбрать любую. Перед сменой версии остановите сервер; сохранения в разных папках независимы. Для первой версии подходит копия папки `.local` до обновления.

С Git: `git switch --detach v1.0.0` (рабочая папка должна быть без незакоммиченных изменений). Вернуться к новой версии: `git switch main`. Новые поля сохранения (аватары и учёт попыток) не используются первой версией.

## Для разработки

Фронтенд — обычные HTML/CSS/JavaScript, сервер — Node.js без внешних зависимостей. Материалы: `public/questions.json` и `public/media`. В первом раунде 28 вопросов, во втором 19; повторяющиеся стоимости сохранены, вопросы различаются номером.

`npm test` проверяет таймер, очки, отмену, совместимость сохранений, HTTP, все фото и восстановление резервной копии. Нужна возможность открыть локальный тестовый порт.

Личные фотографии входят в репозиторий. Учитывайте это при выборе его видимости.
